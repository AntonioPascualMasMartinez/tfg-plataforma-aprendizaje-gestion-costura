## Descripción
Este repositorio contiene el desarrollo del Trabajo de Fin de Grado consistente en la creación de una plataforma web multimedia para el aprendizaje y gestión de proyectos de costura.

## Objetivos
- Gestión de proyectos textiles
- Aprendizaje guiado paso a paso
- Comunidad de usuarios
- Accesibilidad y UX profesional

## Tecnologías previstas
- Frontend: Angular
- Backend: Node.js + Express
- Base de Datos: MongoDB

## Estado del proyecto
En fase de desarrollo y planificación

## Estructura del repositorio
- `/frontend`: Aplicación cliente
- `/backend`: API REST
- `/docs`: Documentación técnica y diagramas
- `/scripts`: Pruebas en desarrollo

## Convención en commits
- `init`: estructura inicial del proyecto
- `docs`: añadir esquemas, diagramas de arquitectura y  documentación del proyecto
- `feat`: Añadir funcionalidad o elemento al proyecto
